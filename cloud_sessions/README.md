# cloud_sessions — 云端 Claude Code 会话的原始记录

2026-11-17 起, 开发改在云端 Claude Code 进行(设备被限制联网)。这里存每次云端会话的原始逐字记录, 格式与 `projects/` 下的历史对话相同(.jsonl, 一行一条消息)。

- 文件名: `<日期>_<主题>_<会话编号前 8 位>.jsonl`
- 文件是会话进行到存档那一刻的快照; 同一个会话后来再存档会覆盖成更完整的版本。
- 每次会话的要点整理(人读)在代码仓库 `robot_cell` 的 `docs/云端协作/对话记录/`。
- 本文件夹是新增内容; 仓库里原有的存档文件不改动。
