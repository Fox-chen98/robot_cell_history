**口径(用户认可的说法, 站在高堆看)**: 高堆封住 ①自己列: 后方所有排 + 前一排 ②右边一列(列号更大): 同排 + 后方所有排 + 前一排; 左边一列不影响。"高过"=堆顶高过被操作盒的顶面(放置时=手里盒顶面)。

**同一规律站在被取盒看(沙盘 fp 的记法, 用户逐盒实测, 沙盘 https://claude.ai/code/artifact/99cf22b3-129e-4a4a-8605-04813f44c1b5 的 rule.fp)**: 取/放坑位 (c,r) 时, 工具底面=被操作盒的顶面; 以下坑位的堆只要高过这个面就碰:
- 同列 c: 前方所有排 (r'<r) + 后方一排 (r+1)
- 左列 c−1(列号更小): 前方所有排 + 同排 + 后方一排
- 右列 c+1: 不影响
fp 记法 [列偏移, 排偏移], −99=前方全部: [[0,-99],[-1,-99],[-1,0],[0,1],[-1,1]]。

**Why:** 臂从格口正面伸进去, 臂身和杆横在目标前方上空; 吸盘偏在杆身一侧(TCP偏移x39/y17mm), 所以工具本体压在左前方。不是"盒子间缝隙"问题, 我曾按盒子居中算错(2026-09-10 已收回)。

**How to apply:** 摆放/取货顺序受"前挡后"约束: 高度只能从前往后不降(看台形); 放从后往前, 取从前往后; 深度方向批号先进后出。叠层与退苗直接冲突: 只放一层则无约束。排位规则/退苗方案设计以此为前提; 沙盘里红格=按此规律的预告。关联 [[cell-interface-layering]] [[slot-place-calibration]]。

**2026-09-11 出路已验证(实验分支 exp/stand-place)**: 不转电机、零位携带姿态(吸盘水平朝里, 盒立着)直接推进格口靠上前一盒→贴板→吹开→直线退出, L7_left 真机一次成功(tools/grasp/stand_place.py, 参数 config/stand_exp.yaml: 悬停点→推进263.5(队列每多一盒减22.4)/下降61.3mm)。盒间无高差, 阴影规律不触发, 退苗/锁苗可行, 容量约每通道十几盒×6通道。用户定: 推进前离板10mm, 放下后不抬直接退。主线 main 未动, 标签 before-stand-exp 可回退。 取货(stand_retrieve)同日验证: 压上盒面吸住后先退10mm脱开邻盒再抬(直接抬会把后盒带起)。放/取来回全通。

**2026-09-11 收尾/交接**: 取货推进改一条直线3cm/s不停顿(用户嫌中途停顿), 放/取再次全通。用户下一步: 先压缩上下文, 再**设计立放专用的末端硬件**(去掉腕转电机, 细长吸杆只进自己通道)。设计输入: 格口净高≈176mm(层节距196.4−板厚20), 深度≈430-450mm(账本forward), 宽466mm; 盒60×38.5×22.4立放(60边在底, 高38.5, 厚22.4沿深度), 通道宽60+缝; 现役工具零位吸盘偏杆身39/17mm、杆盒109×53; 现有动作的两条经验(推进前离板10mm, 放下直退不抬, 取时先退10再抬). 实验分支 exp/stand-place(两边仓库), 标签 before-stand-exp; 试验动作 tools/grasp/stand_place.py / stand_retrieve.py, 参数 config/stand_exp.yaml. 标定方案已讨论定案(格口空载3数+持货1数, 盒尺寸加减法), 等新末端到了再标.
