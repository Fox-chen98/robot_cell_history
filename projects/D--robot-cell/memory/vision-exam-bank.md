**考题库方法论**(2026-08-26 起): 真机摆场景→七步诊断(`scripts/vision_steps.sh`)→逐帧判卷→记入 `data/vision_steps/考题库索引.md`(单一账本, 5帧#0~#1e已归档)。每帧run目录永久保留可离线复盘(`vision_steps.sh run_XXX`/`stepN`)。

**侧立盒战役结论**(考题#1系列, 全部实测):
- 远拍(76cm): mask含侧面(合理!)→多面混票→RANSAC流选→pose=None→**生产死循环**(位姿失败无重试出口, pick_and_scan真实bug待修)
- 正拍45cm: 侧面消失+深度双峰33mm真空带, 但**镜面对准热斑**(盒面法线-投光器-镜头三者对齐时结构光过曝致整面深度失效, 盒自歪6.6°可凑齐条件)+mask光环(桌面点)反客当选。条码面只是放大对准容差的从犯
- **防线1(已定稿)**: closeup斜拍10°(`CLOSEUP_TILT`, closeup.py)破坏镜面对准 → 最凶姿态下满血3886点/顶面75%当选/L59.7×W21.3(<0.7mm误差) —— Φ13直吸侧立盒的视觉基础已具备
- 防线2(待实现): 最近簇预处理(深度断档切一刀掐光环), 兜热斑残余+叠放取上层
- 防线3(待实现): 位姿失败N次→拨/异常出口, 灭死循环

**2026-08-27战役收官**: 感知管线定稿九步(拍照→ROI→v3分割0.65→点云清洗→桌面门卫(用户提议:同帧拟合桌面滤除离桌<8mm点)→多脸连片剥离(用户方案B:投票→最大连片→重拟合→剥离循环)→逐脸量尺→逐脸量高(复用门卫方程)→step8场景认亲去重(朝向<6°/共面<6mm/地盘重叠>30%))。考题库20帧: 单盒全姿态+叠放全组合+斜靠变体+贴盒+四盒散布全通过, 每脸输出中心/朝向/L×W/H/倾角五件事实。v2退役v3+0.65默认。旧防线2(最近簇)被桌面门卫取代; 拨原语被'抽枕头'策略取代(平脸优先吸,斜盒随支撑物抽走自己躺平;斜吸留作靠固定物场景备胎)。待办=策略层落地(先吸后判+平脸优先)/v4重训练(工具头负样本+贴盒对+遮挡盒)/斜吸容忍角实验/真空反馈接入。

**closeup判卷链**(动态目标的新姿态上真机的家规流程, 已跑通两轮):
真机回home → `closeup.py --dry`算TOP_POSE → sim_mode on → `vision_steps.sh closeup`(控制器沙盘IK) → read_pose取关节角→登记poses.yaml(closeup_t1/t2/t3已有) → go_home → `check_motion.sh <名>`录制判碰Foxglove回放 → 绿 → sim off → `go_real.sh <名>` → step1拍摄。

**Why:** 镜面热斑是"脆弱巧合"(差几度天壤之别), 结论全靠对照实验钉死, 压缩后勿凭直觉推翻; 考题库=调参/换权重/策略判据的回归考卷。
**How to apply:** 视觉不准先跑七步诊断看哪步先崩; 立盒场景一律走斜拍closeup; 新近拍目标必须走判卷链。相关: [[tcp-handeye-standardization]] [[yolo-seg-project]]
