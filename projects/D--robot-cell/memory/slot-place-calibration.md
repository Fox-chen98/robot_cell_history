**格内放置方案(2026-09-01 与用户定案)**: 末端=步进电机(柜子DO三档)+吸盘(TCP)。抓取时电机零位吸大面; 到格口悬停点**在格口外转90°**(避开格内翻转扫掠空间), 盒变成平躺托在吸盘下 → 水平插入 → 落到层板 → 吹开。转向表(config/slots.yaml place.rotate_by_slot): **L5~L8=DO1顺90° / L1~L4=DO2逆90°**(低层J6构型镜像)。

**为什么标定必须手动示教**: 转90°后吸盘实际横伸, 但URDF没有电机这个关节, 仿真工具碰撞模型仍是零位形状 → **格内判卷的"碰撞极限"是假的**。故边界由人眼+示教器实测(`scripts/arm/calib_slot.sh <格口>`, 引导式8向: 深处/左/右/向下触层板/向上碰上层板/架口基准齐平; 首尾自动接库路径 mid↔格口, 闭环可连标下一格; 跳过的方向合并旧账本; **全程不需要AutoDL**)。产物`data/slot_range/<格口>_place.json`。

**转90°放置形态的工具几何三常数(L6_left实测钉死, 此前完全未知)**: 吸盘比TCP**靠后60.3mm**(架口基准192.7−悬停离架132.4)、比TCP**低37.7mm**(层板实测z−模型层板z)、工具在吸盘**之上占72.9mm**(格口净空176−竖向可用103.5)。放置高度公式: 第k层(k从0) **TCP z = board_z + (k+1)×盒高**。

**L6_left账本(2026-09-01)**: 横向可达465.8mm/格内深度红线437.7/架口基准192.7/层板面TCP z=0.7347/竖向可用93.5(工作值)。**容量 7列×5排×4层=140盒**(盒60×38.5×22.4, 间距10mm, 各向余量10mm)。列数按"吸盘可达跨度÷(盒长+间距)+1"算=7: 横移极限的限制物是**工具**(110~129mm宽)而非盒(60mm), 盒完全在工具影子里, 故盒可放到每个可达位(待放盒时看最外列与立柱间距证实)。排数5(60.3mm水平偏移吃掉一排)。层数4(v1的3层因换工具作废)。

**v1不可继承**(用户2026-09-01明确): 末端工具已换, v1一切几何数据(placement_maps偏移/3层/reach)作废; 只留非几何参数**box_gap=10mm**(且仅作起点值)。
