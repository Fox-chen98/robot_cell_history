2026-11-02 工具箱「视觉训练」全流程本机走通: 逐张审图(46→14 张要标注) → X-AnyLabeling+SAM 标 → 归档 → dataset_v3(125) → 训练 9 分钟(142 轮早停, 最好第 102 轮) → 对比 → 采用 models/best_v4.pt(16:01, 原 best_v3, 可「回退」).

**Why 采用:** 200 帧只算桌面: 认对的脸两边都 ~225, 认错 8→6; 14 张难例与标注重合 0.76→0.85(影子不再圈进、一盒不再拆成几块). compare_models 判 FAIL 是规则太死(脸数不许少/失败帧不许多): 少的是原先认错的; 失败帧是桌面拟合 RANSAC 随机波动.

**How to apply:**
- 训练: 本机 16GB, 数据加载进程默认 8 会把可提交内存吃光 → 存检查点时内存缓冲区写失败(报 "I/O operation on closed file", 原始错误被训练库重试盖住); train_local.py 已设 workers=2 + 记原始错误 + 自动续训.
- 标注: SAM 点出轮廓后必须「完成(F)」+ 标签 box + 确定, 否则存空文件; 标法=盒子俯视外轮廓, 不圈影子(用户的标法对, 我曾把影子误当端面).
- 对比: quiz_lw --table 只算桌面(H<80mm, 皮带上的盒 H 96~122); 规则待改成"认对不少、认错不多", 失败帧只列不判.
- 采用后过几天用「逐张审有问题的图」看问题图是否变少. 新模型对杆尖上方灰区有 0.26 的低分误认(生产门槛 0.65, 不影响).
