用户的项目：AGV + GCR10-1300 机械臂，末端长杆执行器（Desktop 下 `整体组合.STEP`）做药盒上架。42 步进电机（IM42E）带 ZP3-T13UMSK3-06 吸盘 ±90° 旋转；真空经杆内 PV6 弯头、杆侧面开口出管到金具快插（气口朝杆方向，与管同轴）。

气管方案演进（2026-07）：
- 原方案：2~3 圈 PU 弹簧管 → 螺旋失稳、±90° 力不对称、翻面、挤入电机缝隙；
- 已验证：普通 95-98A 直 PU 管（6×4）效果好多了（2026-07-09 用户确认）；
- 软管 TUS0604 实测失败（2026-07-10）：±90°（最远工位）没问题，0°（最近工位）管被压缩打死折——软管抗压杆能力不足；剪短/定向/防折簧均无效。结论：**98A 的挺度是该布置成立的关键，最终方案退回 98A 直管**。注意：实际远近工位与 STEP 估算相反（±90 最远、0 最近）；
- 备用方案（大概率不用）：①残余扭转→KSH06-M5；②轴线线夹（旋转轴延长线上加管夹，轴上点到接头圆周等距→管长恒定，未实测）；③末端自带 24V 微型隔膜泵（用户曾想用无线真空吸笔，被否：吸力 140g 级、纸盒漏气、无接口、电池）；
- 最新定案方向（2026-07-13，用户提出）：**侧进气 ZP3（Y型）+ KSL06-M5 直连方案**——KSL 外牙直接拧进侧进气金具的 M5 内牙口，支架把该口摆在旋转轴线上（口朝外背向电机）；转接件退化为纯机械打印支架（抱轴+夹金具杆身），体内无气道、无气密要求，气路全在金属成品件内。方案演进补充（2026-07-13 晚）：**ZPR13 因尾长60mm导致总宽超原机(110)约60mm被否**（原机摆臂骑在出轴上,全宽110）。当前两个终选：**方案C** = ZP3-Y13UMSK3-B5短金具+偏置10.5（宽≈原机+5，管子微摆φ21小圆，装配动画 artifact ffa0ca43）；**积木式** = KSL+金属直角块(现成M5内牙直角件或CNC铝块)+中空M5加长杆+M5缓冲吸盘头（口在轴线零偏置零管动、宽≈原机、无一体化金具依赖，装配动画 artifact 06cbc3e3）。装机进展（2026-07-16）：零件到货，用户自设计摆臂（一块板双孔：上孔抱电机轴、下孔双螺母夹金具杆）完成装配，新装配体已更新到 Desktop\装配体\整体组合.STEP（内含 KSL06-M5 + ZP3-Y13UMNJ6-B5 模型——J6 仅为下载模型，**实际购买为 K 系防转版**）。待办：五项测试（手转对称性/纵线/游走/通气/量偏距与探出量）。药盒实际最重仅 50g（此前扭矩按 300g 估算过于保守，余量 ~10 倍）；用户曾考虑缩小电机（35/39 一体化闭环 RS485 需确认货源）。
**最终定稿（用户拍板，2026-07-13）：方案C**——用户明确偏好简单直连，积木式作为备选存档。吸盘支架_v2.py 已切回方案C参数并重新生成（STEM_HOLE=8.6/PORT_OFFSET=10.5/XS=-10，吸盘面28）。方案C成立依据：其管子状态（零扭转+微摆）严格优于用户已实测满意的"98A直管+普通快插"。历史记录：曾选型 **SMC ZPR13USK10-06-A10**（平型/硅胶/K防转/行程10/M10×1杆/预装φ6快插可拆——SMC图纸标明快插经M5×0.8拧入，拆下换KSL）。**口心到盘面 E=29.9≥26 → 口完全同轴（PORT_OFFSET=0），吸盘半径30≈原机28**。曾发现的关键约束：吸盘面半径必须＞电机半宽21+余量（原机28的由来）。ZPR较长（口心以上~60mm），金具须置于杆外侧（XS=-30，杆宽±23）尾部沿杆外侧掠过。支架 v2 已按此生成（桌面 吸盘支架_v2.py/.stl/.step：抱轴孔φ5.2待核电机轴、板孔φ10.6、板位y=-33）。五步装配动画等 artifacts 已交付。待办：下单金具（S硅胶版，无则N）+核实电机出轴φ和长度。此前的"一体气路块"方案（内部L形钻孔）作为备选保留。
- 重要背景（2026-07-13）：用户最初的方案就是**无电机立放**（药盒压底板+里板/前盒），因对点精度地狱+杆必须做细而放弃，才加了末端电机翻转平放。讨论出的 v2.0 候选：**铲刀式无电机杆**（杆居中飞行+薄板下沉吸盘+缓冲金具+相机在线修正+悬停3mm断真空自落），气管问题随电机一起消失。最终建议：v1.0 完成电机方案交付；并行两实验（薄盒立稳性 / 电机锁0°+视觉修正试放20盒≥95%）；若过且需复制多台→切 v2.0。已做3D动画（立放流程、四重构方案对比、轴线线夹演示等 artifacts）。
- 金具气口确认为 M5（原装接头是 PC6-M5 直通快插）；最终倾向：**PC6-M5 + 直管即为默认方案**（电机轴⊥管轴，扭转分量天生小）。KSH06-M5 旋转快插（PC6-M5 旋转版，长约 33mm 比 PC 长 13mm，装后需重剪管长、查扫掠干涉）仅在"纵线测试"（管画纵线跑 20-50 循环看是否变螺旋）不过关时启用。KS 系列真空可用（-100kPa）但有微漏，不能用于关阀保压。

关键几何（从 STEP 量得）：旋转轴沿 X 在 y≈316；金具接头偏轴约 28mm，±90° 搬运弧长约 44mm；PV6 到金具直线距离约 100mm（0° 最远）；建议管自由段 ≥60mm，剪管约 150-160mm。

## 最终装机定稿（2026-07-16/17，实物状态）
装机后暴露的新问题：KSL06-M5 的旋转自由度确实把**扭转**拉力降到很小，但残余管拉力/自重转向了**轴向**——带缓冲版 ZP3-Y13 的弹簧在侧向进气布置下**未吸物时就被预压缩**，且随姿态变化，导致 TCP 标定不准、放置高度随负载漂移。
解法：换成**无缓冲的刚性金具 ZP3-Y13UMS-B5-B5**（平型白色进口硅胶；勿购 B 风琴型，橡胶弹簧同样破坏刚性）。它没有自带安装杆，故外配 **M5×0.8 全牙牙条**（304，备 35/45/60 三种长度）+ M5 螺母/弹垫/平垫两侧对夹；牙条涂螺纹胶拧入金具顶孔 M5×0.8，侧口 M5×0.8 接 KSL06-M5（顶孔与气道不通）。
**摆臂下孔 φ8.8 → φ5.5**（旧 M8×0.75 杆改 M5；打印件可取 5.8），上孔与孔位不变。
**装配关键尺寸**：吸盘面调至距电机轴线 **28mm**（电机半宽21+余量7）后锁死；锁死前侧口转向正对外侧背向电机，KSL 轴线平行电机轴；牙条余长先拧螺母再锯、退母校牙。
