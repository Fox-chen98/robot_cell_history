用户负责"上苗机"药盒上料线的机械臂部分（xMate SR + 吸盘，见 [[arm-gripper-air-tube]]）。原设备为外协非标机，厂家不提供图纸也不改设计；用户因机械臂行程调低了料台，导致提升带落差过大，决定自主逐件复刻设计（SolidWorks 参数化建模 → 嘉立创等外协制造 → 自行组装）。

**进展（2026-07-24）**：第一个零件"料台钣金台面"已在 SolidWorks 2024 建模完成（用户为 SW 新手，全程按步骤指导）。结构：几字形，顶板 + 两长边下折边，短边开放（侧面扫码相机支架装型材槽）。机架为**欧标 3030 铝型材**。

**全局变量参数表**：L=710、W=395（外廓）、H=30（折边外廓高）、t=2mm、内R=2、K=0.4、holeH=17（槽顶圆心距台面上表面 = 槽中心15+t2）、slotW=7（下开口 U 形槽，每边 3 个）、slotPitch=290（用户微调值）、扫码窗口 117×87 R10。

**遗留核实点**：窗口到短边/长边的距离，模型为 118/62，用户口述为 62/118，曾提醒核实；底部扫码器吊装支架螺丝孔与 HMI 开口未加入模型（用户表示按现状即为成品）。

**How to apply**：后续继续复刻其他件（侧相机 L 支架、机架型材清单、爬坡输送机等）时沿用同一流程：全局变量驱动 → 导 STEP → 用脚本解析 STEP 检验（PowerShell 解析 CARTESIAN_POINT/CIRCLE 已验证有效）→ 嘉立创下单（钣金选 SPCC 2.0 + 哑光黑粉末喷涂以解决台面反光干扰视觉的问题）→ 首件试装再批量。
