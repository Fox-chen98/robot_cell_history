机械臂场景：右/后是不锈钢存储货架，左是上料台（绿色传送带+料斗+药盒）。

**J1 方向安全约束**：
- J1 数值**变小** = 胳膊转向**货架侧**（安全）
- J1 数值**变大** = 胳膊转向**绿色传送带/上料台**（危险，会撞）

`初始位姿` J1=135.76°（高位、工具指货架上部、货架侧），`scan_position` J1=−13.79°（插进货架格位、低位、货架侧）。两端都在货架侧。
所需运动 = J1 从 135.76° **一路减小** 到 −13.79°（−149.55°），天然就是安全方向。

护栏：示教 [初始位姿→scan_position] 时 J1 只能单调变小，**绝不能变大、绝不能走 +210° 绕远路**那条（会把臂甩过上料台）。

避障路点法（5 点离散示教，停稳记录，movej2 融合回放）见 [[teach-replay-pipeline]]：①工具退出货架面 ②货架前空域翻腕(J5+227°等) ③对准目标格(J1 只减小) ④伸入格位 ⑤精校到 scan_position。主障碍=货架层板/立柱+沿臂橙色螺旋电缆；上料台仅在 J1 转错方向时才成威胁。
