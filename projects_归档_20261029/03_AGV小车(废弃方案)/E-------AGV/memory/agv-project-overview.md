用户（第一次做AGV）在 E:\小车设计\AGV 自制一台磁导航AGV小车，因市面买不到合适尺寸的成品，自购零件组装。

- 理想样式：参考"Mini小黄人"AGV（图片在 E:\小车设计\AGV\小车理想样式\参考图.png）——质量4KG、载荷1.5KG、尺寸241×210×126mm、最大货物尺寸179×165mm，圆润车身+顶部载物托盘。
- 核心零件清单：轮毂电机×2（ZLLG40）、轮毂电机驱动器×1、主控制器×1、电池×1、RFID传感器×1、磁导航传感器×1、自动回充组件×1。
- 结构方案：车体及零件固定结构件全部3D打印；底板打阵列孔位，其余零件通过3D打印转接件或铜柱连接到底板上（便于首次开发试错调整）。
- CAD：SolidWorks 2024，装配体导出为 整车装配.STEP；截至2026-07-10已有 AGV_底板 + 两个电机ZLLG40（对称布置，轮距约248mm）。
