用户首次设计AGV，参考现成大车（约472×442×347mm）定制一台Mini车。目标外形参考"Mini小黄人" 241×210×126mm（**高度可放宽**），载荷1.5kg，室内平整硬地，巡航0.5~1m/s，续航4~8h，需多车无线调度。导航用磁条+RFID。

**已确认选型（均为深圳中菱/WHEELTEC同系生态）：**
- **轮毂电机**：4寸 ZLLG40ASM100 ×2，24V，额定2N·m/5A，1024线编码器+霍尔+热敏，单轴M12×1.5，单只1.5kg。注意额定转速450rpm偏高(对应2.5m/s)，实际只用低速段→必须配伺服闭环驱动器+软件限速到~180rpm。
- **驱动器**：ZLAC8015D 伺服双轮毂驱动器（一台驱两轮），输入20~48V，CAN(CANopen)/RS485，带编码器闭环正好治低速抖动。原厂配套。注意：速度>100rpm建议加泄放/制动电阻(5Ω 100W)。
- **主控**：WHEELTEC C63A（STM32F407+FreeRTOS，75×75mm），通过CAN对接8015D；自带ICM20948 IMU、6路超声波、2路RGB、OLED、蜂鸣器、急停、双5V5A Type-C输出(给上位机供电)。输入10~28V。是ROS下位机，多车调度需另配带WiFi上位机(树莓派/Jetson)。
- **电池**：P760S 磷酸铁锂 7S1P，标称22.4V/**满电仅25.55V**(<C63A的28V上限)/6000mAh/134.4Wh，最大持续15A，146.3×177×42mm/1750g。满电低于28V→**电池可直供C63A和8015D，无需DC-DC**。用户已确认就用这块(尽管偏大偏重，续航过剩)。

**整车布局结论(2026-06定稿)**：D字形否决，最终采用**圆角近正方形**车体。驱动轮居中(原地自转省空间)。因电池146宽塞不进原122mm两轮净空，选方案C**拉宽轮距**：驱动轮中心移到±118(原±100)，两轮净空159,含轮总宽~277.5。外壳加宽到250(宽)×235(长)×145(高),底板reverted到~220×225。
**分层(3层,铜柱撑)**：第1层底板(离地~30~50,RFID需要时抬到50)放**驱动器+RFID**(RFID开方孔朝下读地面,必须在车宽中线Z=0压磁条);第2层放**电池**(几乎占满);第3层放**C63A+上位机**。整车高~150mm。
**SolidWorks建模进展**：外壳已拉伸/抽壳/圆角/分割成上壳(黄#F0B923/240,185,35)+底圈(黑)+轮拱;底板带电机让位缺口;驱动轮ZLLG40真模型(已另存为电机ZLLG40.SLDPRT,原STEP是CATIA装配体导入有临时文件丢失问题,改用"导入装配体作为多实体零件"或简化占位块);C63A详细模型120万三角面/开图90秒太重,要换75×75×23占位块;主装配体=整车装配.SLDASM。轮子贴地、轴心53.5。

- **自动回充**：WHEELTEC EC130 红外对接套件（充电桩落地216×161×202mm + 车载充电装备）。用户确认需要。车载电子实际很小(S23C板140×47×32mm + 红外接收板15×28×12mm + 极片)，决定自制扁壳(~150×50×35mm)嵌车尾，不用原133mm大盒。链路：极片→S23C→DC头接P760S的DC4.0×1.7充电口；T头分接电池主供电；2Pin信号接C63A(有轮毂电机版回充源码)。⚠️充电桩里的适配器必须是磷酸铁锂充电器(25.55V/3A)，不可用三元锂29.4V。远距离靠磁条+RFID导航到桩附近，近距离红外微调对接。
- **传感器**：磁导航IGK-G416(~200×35×35mm长条,485) + RFID IGK-R500(~80×80×40mm,485)。两者485共用C63A单个485口(需确认都Modbus-RTU从机/地址不同/波特率一致)。**IGK-G416最低点须≤40mm离地**(硬约束)，RFID读卡高度宽松。
- **脚轮**：万向PU脚轮，按**安装高度TIH≈53mm**选(约2"~2.5")，非按轮径。布局2驱居中略低1~3mm+前后2脚轮保证驱动轮压地。

**整车尺寸(方案B,推荐)**：底板离地53mm(正好=驱动轮Φ107轴心高,电机轴直接装底板平面,支架最简单)；磁导航吊到~28mm,RFID~42mm。整车约 长285~295 × 宽175~185(车体)/250~260(含外露轮) × 高~140mm。比参考241×210×126宽出一圈,主因是P760S电池宽146mm顶宽了两轮间距(若想回到210宽需换小电池)。布局上下两层:下层电池+驱动器,上层主控+上位机+传感器,轮子两侧露出。

**讨论顺序**：电机✅→驱动器✅→主控✅→电池✅→自动回充✅→传感器✅→脚轮✅→下一步：安全件(急停/防撞)→上位机(WiFi调度,树莓派/Jetson,由C63A 5V5A口供电)。

**电池换型评估(2026-06,已否决)**：曾评估换成 E626S(6S三元2550mAh/55Wh)——体积仅1/5、337g能解决装配,但续航只~3-4h不达标(单块)、峰值电流贴边、自动回充充电器/接口/低电量阈值全要改。**用户决定保留 P760S(磷酸铁锂6000mAh/134.4Wh)**,现有设计不变。注:磷酸铁锂放电曲线平,低电量靠电压不准,阈值设~20V报警,精确需库仑计;自动回充充电器用磷酸铁锂25.55V/3A。

**底板↔底圈连接(2026-06定稿)**：**四角弧形凸台(顺底圈内壁圆弧,长在底圈上) + M3热熔铜嵌件 + 顶部螺丝**。凸台在底圈(带嵌件孔Φ4.2),底板四角只开过孔Φ3.6,螺丝从底板上方拧进底圈凸台。四角避开电机(两侧中)和脚轮(前后中)。FDM件通用紧固=热熔嵌件(可反复拆)。待议:底板中间抗下沉(6mm+铜柱靠角或加井字筋)。示意STEP:底板-底圈连接_四角圆弧.step。

**尺寸放大(2026-06,进行中)**：因FDM打印机256×256×260,宽度被床+轮距双封顶(只能~248),放大主要在长和高。目标:外壳 宽248×长248×高180,底板 231×231×厚6(=外壳-17,每侧缝6mm,打印余量4mm/边需加brim)。用户正在SolidWorks改:外壳改底层草图长宽+拉伸高度(上壳/底圈联动),底板改草图+厚度+补轮缺口到新边缘(内边仍±75)。改完再加四角弧形凸台。
**底板实测&厚度定案(2026-07,由AGV_底板.STEP解析)**:底板当前实为 **宽220×长225×厚5**(关于中心±110/±112.5对称,尚未放大)。本次放大=平面 220×225→231×231 + **厚度5→6mm(方案A,定案)**——加厚为配M3×L5热熔嵌件(6mm板压入后底留1mm不穿透)、且挖网格孔后更抗下沉。桌面文件:C:/Users/26293/Desktop/AGV_底板.SLDPRT + AGV_底板.STEP。

**底板网格化(2026-07定,面包板思路)**：底板放大到231×231×6后,改做「规则网格安装孔」平台——间距**20mm**、以底板中心对称布孔(中线Z=0有孔,便于对齐RFID等居中件),各部件(电池/驱动器/主控)做**独立小支架**分别拧到网格,模块化便于逐个打印验证/调布局。紧固走「**甲方案**」:底板只打光孔,用到哪孔就用**烙铁烧M3热熔铜嵌件**进去、螺丝**从顶面**拧进嵌件(全顶面操作免翻车;嵌件半永久,挪位置=换孔烧新嵌件)。嵌件**敲定:金超 M3×L5×OD4.5 黄铜斜纹热熔款**(L5配6mm板不穿透、底留1mm;OD4.5是M3主流标准外径,抓力比OD4.0紧凑款强一档,网格板反复拧支架更耐用;曾在OD4.0/4.5间纠结,最终选4.5)。网格孔**建模Φ4.2→打印后≈Φ4.0**正好卡OD4.5嵌件(孔比OD4.0款仅大0.4,对20mm间距网格几乎不削弱强度);以卖家推荐开孔径为准+0.2补FDM缩孔,首件实测微调。网格**避开**:两侧电机让位缺口/四角底圈连接凸台孔/前后脚轮位/RFID朝下方孔。**电机支架是特例**(夹M12轴+10mm平口dropout式),但安装脚也落在网格上。承重提醒:100个孔削弱板,电池~1.7kg压中间易下沉→电池支架跨四角受力或电池下方少打孔/加井字筋。缺口实测(由STEP):在**宽Z=±110两侧**,每个**长X±60、内壁Z±75(深35)**;放大到231后内壁保持±75、外缘随边到±115.5,SW改草图时缺口标注(±75/±60)不动只改外框。网格布局定案:11×11=121候选孔,**四角(±100,±100)正好=底圈连接点→那4个Φ4.2孔兼作M3连接过孔(Φ4.2过M3够,省掉单独Φ3.6孔)**;缺口区28孔由"切缺口"这步顺带吃掉,无需手动跳过实例;**可用93孔**。布局图:桌面 AGV/底板网格布局.png(脚本plot_grid.py)。SW建议流程:①改草图放大231×231 ②拉伸厚度5→6 ③顶面画Φ4.2圆种子放角(-100,-100) ④线性阵列方向1/2各11、间距20 ⑤缺口自动吃掉28孔。**进度:①②已完成(2026-07-01,STEP验证X231/Z231/厚6/缺口内壁±75外缘±115.5/圆角R38均正确),下一步③④打网格孔(种子Φ4.2放(-100,-100)+11×11线性阵列间距20)。**③④网格孔已完成并验证通过(2026-07-01):93孔/Φ4.2/X,Z均间距20×11(-100..100)/缺口区0孔/圆角R38。底板这一件正式完成。** ⚠️验孔教训:用"顶面圆弧Center"法会被STEP把整圆拆成两半弧坑到(误判186孔/Φ4.98),**验孔径与孔数必须用"读圆柱面几何"法**:OCP BRepAdaptor_Surface→Cylinder().Radius()与Axis().Location(),按(半径,轴XZ)去重才准。**下一步:打印首件验孔径**(建模Φ4.2打后应≈Φ4.0卡OD4.5嵌件),建议先打小测试条锁死孔径再打整板。****材料定案:PETG**(2026-07;载电+反复拧嵌件,烧嵌件温度~230℃)。待定:首件实测孔径。

**控制架构决策(2026-07,重要变更)**：用户决定**去掉车载上位机(树莓派/Jetson)**——磁导航AGV路径由地面磁条决定,不需车载高算力;C63A单机即可完成单车全部控制(循磁条+读RFID站点+CAN控电机+超声波避障+急停)。好处:省~5-15W,平均功率从~40W降到~25W,**续航从~2.7h提到~4h+**,省车内空间与一路5V。⚠️但"多车无线调度"是C63A做不到的(它是STM32F407,**板载无WiFi**,只有蓝牙接口UART2默认连APP、近距离点对点不适合多车)。查证(C63A-V2.1接口图+资源分配表):板载无WiFi芯片;WHEELTEC**配一个WiFi模块但官方用途是"无线烧录程序"**(串口WiFi透传模块,插串口)。判断:该模块本质=串口WiFi透传,**大概率能复用做运行时多车调度通信**=上一轮说的"轻量WiFi模块",现成~1W。目标架构:**C63A(单车控制)+WHEELTEC WiFi透传模块(联网)+中央PC(调度,不在车上)**,全程不用车载树莓派。**待用户确认**:①该WiFi模块能否运行时串口透传(非仅烧录,看WIFI模块使用说明.mp4或问WHEELTEC客服)②多车模式(先单车/各跑各独立路线/共用路网中央调度)。多车调度主流走WiFi(星型:中央PC↔各车,车间布AP);数据量小(站点/电量/派单),WiFi绰绰有余。**WiFi模块选型(2026-07):弃用WHEELTEC烧录模块(稳定性不足),改用有人物联工业级串口WiFi模块。确定用 有人 USR-WIFI232-B2(¥48)**——已核实(usr.cn/Product/166):**串口TTL/3.3V供电(与C63A串口2完美匹配,直连不用转电平)、外置天线I-PEX达280m、带100M以太网口(兜底)、波特率300-460.8k、销量4万+口碑最好**;⚠️不原生MQTT(只TCP/UDP/HTTP)→走TCP透传,调度协议放中央PC端(或PC跑MQTT broker桥接)。备选C210(¥9,TTL低功耗小,工业特性弱)。接法:B2 UART TX/RX↔C63A串口2 RX/TX交叉+3.3V+共地。**下单配置:外置天线版(必选!车内电池/电机金属多会屏蔽内置天线,外置天线伸出壳外/贴壳内壁远离电机电池)+3dBi棒状天线+"测试底板"(把模组引脚引出排针,杜邦线免焊直连C63A)。**注意W610是RS232/485电平(非TTL),接C63A需转电平,故不选。

**磁导航传感器支架(2026-07设计,方案A前伸):** IGK-G416实测**200(长)×52(宽)×18.6(厚)**,可用安装孔=顶面2个**Φ4.3(M4)、间距70、关于长度中心对称**。**底板离地实测:底面24mm/顶面30mm(很低)**。因底板太低+传感器厚18.6,传感器藏不进底板下→**选方案A:传感器装底板前缘外、车头前伸52mm**(否决方案B底板开大槽)。支架参数(车坐标X长+前/Y宽/Z高):传感器长向沿车宽Y居中(±100)、最低面离地**32mm**(≤40)、顶面50.6、探出X[115.5,167.5]、孔@(X133.5,Y±35,顶面)。支架:后固定板X78-112/Y±46/Z30-34,4×M3(Φ3.6)@(X80/100,Y±20)拧底板网格;前托板X122-146/Y±46/Z50.6-54.6,2×M4(Φ4.5)@(X133.5,Y±35)压传感器顶;两侧梯形撑板Y±40-46厚6。文件:桌面AGV/磁导航支架.step+_预览.png。⚠️待确认:传感器孔是螺纹还是光孔(定固定方式);外壳前部要罩探出的传感器;可选长圆孔做左右微调。

**RFID标签传感器支架(2026-07):** IGK-R500实测**80×80×厚34.5**(连接器从一侧伸出),4×Φ4安装孔间距70×70。**读卡距离0-18cm(180mm)、134.2K低频、FDX-B、支持485/CAN/232**。关键:低频RFID**能透PETG塑料底板**+读距180mm≫底板顶到地面30mm→**方案:RFID装底板上方、检测面朝下、隔6mm PETG底板透板读地标(36mm≪180)**,不占底盘下/不加车长(比磁导航简单)。⚠️铁律:读窗正下方(底板+下方24mm间隙)不能有金属(挡RF),布局留净空。支架=**转接板(通用件,与RFID在车上位置无关,定稿2026-07)**:方形**80×80×厚8 PETG+4角R10圆弧**(R10由3D实测:外形圆角圆心±30+R10到±40=半宽80/2)。**RFID安装孔实测65×65(非70!四角±32.5)**;图纸的70是外壳盖螺丝/内框。**全用M3(和底板统一,不用M4)**:①4角**Φ4.2孔@±32.5**烧M3×5嵌件——RFID坐板上、检测面朝下,M3螺丝穿RFID的Φ4孔拧入(Φ4孔配M3松1mm好装,RFID读地标定位不严);②中心**4×M3沉头过孔@±20**(Φ3.6过孔+Φ6.5沉头,沉头使螺丝头不顶RFID)接底板网格。螺丝:**4角M3×35圆柱头**(穿RFID28mm+转接板嵌件5→需33,故转接板加厚到8mm防M3×35穿出);**中心M3×14沉头**(穿转接板8+底板嵌件5)。嵌件全用**M3×5×OD4.5**(同底板)。装配顺序:先中心M3拧底板,再4角M3装RFID(RFID盖住中心孔)。文件:桌面AGV/RFID转接板.step。RFID装底板位置/连接器朝向用户自行调试(中心4×M3对齐任一(±20,±20)网格即可)。⚠️读窗正下方留无金属净空。**RFID抬高(2026-07):**因RFID占空间可能干涉电机支架,决定用柱子把"转接板+RFID"整体撑离底板。**选尼龙柱非铜柱**(134.2k低频RFID怕天线周边金属,尼龙对RF透明且强度够)。已购:**金超 M3尼龙单头六角隔离柱(阳-阴),阳头+6mm(配6mm底板:嵌件5+底孔1正好齐平,勿买+8),本体10/15/20/25/30五档**各一包测试用。装法:阳头拧底板网格嵌件→阴头朝上→M3×8沉头穿转接板中心孔拧柱顶,4根@±20。抬高后读距仍富余(抬30时检测面离地~68≪180);尼龙柱可阳阴串联拼高。**磁导航L支架开孔(2026-07):**用户自画L支架(100×52×28,水平臂厚8?后说5mm),水平臂开**4×Φ3.6过孔一排@间距20**(对齐底板网格),螺丝**M3×10圆柱头不沉头**(穿5mm臂+嵌件5;若臂8mm则M3×14)。
